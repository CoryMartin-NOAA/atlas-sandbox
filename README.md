# atlas-sandbox

This is a sandbox repository for testing and experimentation within the NOAA-EMC ecosystem.

## Purpose

This repository serves as a testing ground for:
- Experimenting with new features and workflows
- Testing repository configurations and automation
- Development and prototyping before moving code to production repositories
